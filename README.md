# intersect

本地优先的对话与角色管理应用,界面用 Jetpack Compose 写。

数据只存在本机:没有服务端账号,不联网也能翻看历史记录。

## 功能

- **会话与角色**:与内置助手对话,也可以自建角色,写身份、性格和签名,换自定义头像。
- **多服务商**:密钥按服务商登记,模型跟着密钥走;每个会话可绑定某条密钥,也可以跟随默认。
- **用量账本**:每条回复的 token 与费用都记账,能按模型、按日期、按会话查看并导出。
- **备份**:通讯录、会话、密钥配置可打包导出,支持口令加密。
- **状态与主题**:名片上切换在线状态,主题跟随系统或手动切换明暗。

## 构建

```sh
sh gradlew :app:assembleRelease
```

`release` 用仓库外的正式签名,路径与密码读自 `local.properties`(不入库),也可用 `-P RELEASE_*` 传入。配置缺失时会回退 debug 签名,并在构建日志里打印 `[signing]` 警告。`debug` 包由本机 debug keystore 签名,可与 `release` 包并存。

## 开发方式

本项目有 AI 参与制作:代码、图标生成脚本与文档由 AI 辅助完成,功能取舍和结果验收由人工负责。

界面布局与交互范式的灵感来自扔物线《三小时用 Compose 写个聊天界面》的示例项目 WeCompose。本项目为独立实现,不包含该示例的源代码、图标、头像或其它素材。

`tools/` 下是生成界面图标与启动图标的 Node 脚本(无第三方依赖),在项目根目录执行。
